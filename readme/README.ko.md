# BesideOS

**지금 사용 중인 운영 체제 옆에 다른 운영 체제를 설치하세요. USB 드라이브가 필요 없습니다.**

BesideOS는 배포판의 공식 서버에서 ISO를 내려받고, SHA-256 체크섬을 확인하고, 디스크에 공간을 만들고, 한 번만 쓰는 부팅 항목을 설정합니다. 무엇이든 기록되기 전에 계획을 검토하고 확인하며, "실행 취소"로 이전 상태를 되돌릴 수 있습니다. 무료, 오픈 소스(MIT), 텔레메트리 없음, 20개 언어.

# BesideOS

**Asenna toinen käyttöjärjestelmä nykyisen rinnalle. Ilman USB-tikkua.**

BesideOS lataa virallisen ISO-tiedoston jakelun omilta palvelimilta, tarkistaa sen SHA-256-tarkistussumman, vapauttaa levyltä tilaa ja luo kertakäyttöisen käynnistysmerkinnän. Tarkistat ja hyväksyt suunnitelman ennen kuin mitään kirjoitetaan, ja ”Kumoa” palauttaa aiemman tilan. Ilmainen, avoin lähdekoodi (MIT), ei telemetriaa, 20 kieltä.

**Verkkosivusto ja lataukset: [besideos.com](https://besideos.com)** · Windows (`.exe`) · Linux (`.deb`, `.rpm`, `.pkg.tar.zst`)

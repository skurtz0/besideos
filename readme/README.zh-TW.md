# BesideOS

**在目前的作業系統旁邊安裝另一個作業系統。不需要 USB 隨身碟。**

BesideOS 從發行版自己的伺服器下載官方 ISO，驗證其 SHA-256 校驗碼，在磁碟上騰出空間，並設定一次性開機項目。寫入任何內容之前，你會先檢視並確認計畫；「復原」可回到先前的狀態。免費、開放原始碼（MIT）、無遙測、支援 20 種語言。

**網站與下載: [besideos.com](https://besideos.com)** · Windows (`.exe`) · Linux (`.deb`, `.rpm`, `.pkg.tar.zst`)

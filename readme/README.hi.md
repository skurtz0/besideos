# BesideOS

**जिस ऑपरेटिंग सिस्टम को आप चला रहे हैं, उसके बगल में दूसरा ऑपरेटिंग सिस्टम इंस्टॉल करें। USB स्टिक की ज़रूरत नहीं।**

BesideOS डिस्ट्रीब्यूशन के अपने सर्वर से आधिकारिक ISO डाउनलोड करता है, उसका SHA-256 चेकसम जाँचता है, आपकी डिस्क पर जगह बनाता है और एक बार चलने वाली बूट एंट्री सेट करता है। कुछ भी लिखे जाने से पहले आप योजना देखते हैं और पुष्टि करते हैं, और "पूर्ववत करें" पिछली स्थिति लौटा देता है। मुफ़्त, ओपन सोर्स (MIT), कोई टेलीमेट्री नहीं, 20 भाषाएँ।

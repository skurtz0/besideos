# BesideOS

**在当前操作系统旁边安装另一个操作系统。无需 U 盘。**

BesideOS 从发行版自己的服务器下载官方 ISO，校验其 SHA-256 校验和，在磁盘上腾出空间，并设置一次性启动项。写入任何内容之前，你会先查看并确认计划；“撤销”可恢复之前的状态。免费、开源（MIT）、无遥测、支持 20 种语言。

**网站与下载: [besideos.com](https://besideos.com)** · Windows (`.exe`) · Linux (`.deb`, `.rpm`, `.pkg.tar.zst`)

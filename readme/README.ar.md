# BesideOS

<div dir="rtl">

**ثبّت نظام تشغيل آخر بجانب النظام الذي تستخدمه. بدون ذاكرة USB.**

يقوم BesideOS بتنزيل ملف ISO الرسمي من خوادم التوزيعة نفسها، ويتحقق من مجموع SHA-256 الخاص به، ويفسح مساحة على قرصك، ويُعدّ مدخل إقلاع لمرة واحدة. تراجع الخطة وتؤكدها قبل كتابة أي شيء، و«تراجع» يعيد الحالة السابقة. مجاني ومفتوح المصدر (MIT)، بلا قياس عن بُعد، بـ 20 لغة.

</div>

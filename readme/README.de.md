# BesideOS

**Installiere ein weiteres Betriebssystem neben dem, das du gerade nutzt. Kein USB-Stick nötig.**

BesideOS lädt das offizielle ISO von den Servern der Distribution herunter, prüft seine SHA-256-Prüfsumme, schafft Platz auf deiner Festplatte und richtet einen einmaligen Starteintrag ein. Du prüfst den Plan und bestätigst ihn, bevor etwas geschrieben wird, und „Rückgängig“ stellt den vorherigen Zustand wieder her. Kostenlos, Open Source (MIT), keine Telemetrie, 20 Sprachen.

# BesideOS

**今使っているOSの隣に、別のOSをインストール。USBメモリは不要です。**

BesideOS はディストリビューション自身のサーバーから公式 ISO をダウンロードし、SHA-256 チェックサムを検証し、ディスクに空き領域を作り、1回限りの起動エントリを設定します。何かが書き込まれる前に計画を確認して承認でき、「元に戻す」で以前の状態に戻せます。無料、オープンソース（MIT）、テレメトリなし、20言語対応。

**ウェブサイトとダウンロード: [besideos.com](https://besideos.com)** · Windows (`.exe`) · Linux (`.deb`, `.rpm`, `.pkg.tar.zst`)

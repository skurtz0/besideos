# BesideOS

**Installez un autre système d'exploitation à côté de celui que vous utilisez. Sans clé USB.**

BesideOS télécharge l'ISO officielle depuis les serveurs de la distribution, vérifie sa somme SHA-256, libère de la place sur votre disque et crée une entrée de démarrage à usage unique. Vous examinez le plan et le confirmez avant toute écriture, et « Annuler » rétablit l'état précédent. Gratuit, open source (MIT), sans télémétrie, 20 langues.

**Site web et téléchargements: [besideos.com](https://besideos.com)** · Windows (`.exe`) · Linux (`.deb`, `.rpm`, `.pkg.tar.zst`)

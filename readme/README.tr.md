# BesideOS

**Mevcut işletim sisteminin yanına başka bir işletim sistemi kur. USB bellek gerekmez.**

BesideOS resmi ISO dosyasını dağıtımın kendi sunucularından indirir, SHA-256 sağlamasını doğrular, diskinde yer açar ve tek seferlik bir önyükleme girdisi kurar. Diske bir şey yazılmadan önce planı görür ve onaylarsın; "Geri al" önceki durumu geri getirir. Ücretsiz, açık kaynak (MIT), telemetri yok, 20 dil.

# BesideOS

**Paigalda teine operatsioonisüsteem praeguse kõrvale. USB-mälupulka pole vaja.**

BesideOS laadib ametliku ISO-faili alla distributsiooni enda serveritest, kontrollib selle SHA-256 kontrollsummat, teeb kettale ruumi ja seab üles ühekordse alglaadimiskirje. Enne kui midagi kirjutatakse, vaatad plaani üle ja kinnitad selle ning „Võta tagasi“ taastab eelmise oleku. Tasuta, avatud lähtekoodiga (MIT), telemeetriata, 20 keelt.

**Veebileht ja allalaadimised: [besideos.com](https://besideos.com)** · Windows (`.exe`) · Linux (`.deb`, `.rpm`, `.pkg.tar.zst`)

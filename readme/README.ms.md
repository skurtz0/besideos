# BesideOS

**Pasang sistem pengendalian lain di sebelah sistem yang sedang anda gunakan. Tanpa pemacu USB.**

BesideOS memuat turun ISO rasmi daripada pelayan pengedaran itu sendiri, mengesahkan checksum SHA-256nya, menyediakan ruang pada cakera anda dan menyediakan entri but sekali guna. Anda menyemak pelan dan mengesahkannya sebelum apa-apa ditulis, dan "Buat asal" memulihkan keadaan sebelumnya. Percuma, sumber terbuka (MIT), tiada telemetri, 20 bahasa.

**Laman web dan muat turun: [besideos.com](https://besideos.com)** · Windows (`.exe`) · Linux (`.deb`, `.rpm`, `.pkg.tar.zst`)

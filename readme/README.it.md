# BesideOS

**Installa un altro sistema operativo accanto a quello che stai usando. Senza chiavetta USB.**

BesideOS scarica la ISO ufficiale dai server della distribuzione, ne verifica il checksum SHA-256, libera spazio sul disco e imposta una voce di avvio monouso. Esamini il piano e lo confermi prima che venga scritto qualcosa, e "Annulla" ripristina lo stato precedente. Gratuito, open source (MIT), nessuna telemetria, 20 lingue.

**Sito web e download: [besideos.com](https://besideos.com)** · Windows (`.exe`) · Linux (`.deb`, `.rpm`, `.pkg.tar.zst`)

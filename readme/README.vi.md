# BesideOS

**Cài thêm một hệ điều hành bên cạnh hệ điều hành bạn đang dùng. Không cần USB.**

BesideOS tải tệp ISO chính thức từ máy chủ của bản phân phối, kiểm tra mã SHA-256, tạo chỗ trống trên ổ đĩa và thiết lập một mục khởi động dùng một lần. Bạn xem lại kế hoạch và xác nhận trước khi bất cứ thứ gì được ghi, và "Hoàn tác" khôi phục trạng thái trước đó. Miễn phí, mã nguồn mở (MIT), không thu thập dữ liệu, 20 ngôn ngữ.

**Trang web và tải xuống: [besideos.com](https://besideos.com)** · Windows (`.exe`) · Linux (`.deb`, `.rpm`, `.pkg.tar.zst`)

# BesideOS

**Instale outro sistema operacional ao lado do que você está usando. Sem pendrive.**

O BesideOS baixa a ISO oficial dos servidores da própria distribuição, verifica a soma SHA-256, libera espaço no disco e cria uma entrada de inicialização de uso único. Você revisa o plano e confirma antes de qualquer gravação, e "Desfazer" restaura o estado anterior. Gratuito, código aberto (MIT), sem telemetria, 20 idiomas.

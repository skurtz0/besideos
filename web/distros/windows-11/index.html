Windows 11

Microsoft'un güncel Windows sürümü.

BesideOS'ta aç

Windows 11, Microsoft'un ticari işletim sistemidir. BesideOS ISO dosyasını dağıtmaz; kendi ISO'nu seçersin veya Microsoft'un resmi sayfasından indirirsin.

Kimler için

Windows'a ihtiyaç duyan uygulama ve oyunları çalıştırmak isteyenler.

Nasıl görünür

Ortalanmış görev çubuğu ve başlat menüsü, yuvarlatılmış köşeli pencereler.

USB bellek olmadan kurulum

  1. ISO'nu seç veya indir: Kendi Windows 11 ISO dosyanı seçersin ya da Microsoft'un resmi indirme sayfasından indirirsin. BesideOS ISO dosyası sağlamaz.
  2. İndirileni doğrula: ISO dosyasının bozuk olmadığını bu sayfadaki bölümden kontrol edersin.
  3. Elle kur: BesideOS şimdilik Windows kurulumunu kendisi yapmaz. Yedek aldıktan sonra kurulumu Microsoft yönergeleriyle yaparsın.

Gereksinimler

  • UEFI desteği ve Secure Boot yapabilen bir bilgisayar
  • TPM 2.0 (resmi gereksinim)
  • 64 bit işlemci
  • Kurulum için yeterli boş disk alanı
  • Geçerli bir Windows lisansı

Resmî indirme sayfası: https://www.microsoft.com/software-download/windows11
Lisans: Ticari (Microsoft lisansı)

Windows 8.1

Başlat ekranı kutucuklu eski Windows.

BesideOS'ta aç

Windows 8.1, Microsoft'un ticari işletim sistemidir ve artık güvenlik güncellemesi almıyor. BesideOS ISO dosyasını dağıtmaz; kendi ISO'nu getirirsin.

Kimler için

Eski bir program ya da donanım için Windows 8.1 gerekenler.

Nasıl görünür

Tam ekran renkli kutucuklardan oluşan Başlangıç ekranı ve klasik masaüstü.

USB bellek olmadan kurulum

  1. ISO'nu seç veya indir: Kendi Windows 8.1 ISO dosyanı seçersin. BesideOS ISO dosyası sağlamaz.
  2. İndirileni doğrula: ISO dosyasının bozuk olmadığını bu sayfadaki bölümden kontrol edersin.
  3. Elle kur: BesideOS şimdilik Windows kurulumunu kendisi yapmaz. Yedek aldıktan sonra kurulumu kendi yönergeleriyle yaparsın.

Gereksinimler

  • 64 bit ya da 32 bit işlemci
  • Kurulum için yeterli boş disk alanı
  • Geçerli bir Windows lisansı
  • Güvenlik için internete bağlamamanı öneririz

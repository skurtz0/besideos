Windows Server 2025

Sunucu ve laboratuvar denemeleri için Windows.

BesideOS'ta aç

Windows Server 2025, Microsoft'un sunucu işletim sistemidir. Deneme sürümü Microsoft'un resmi sayfasından indirilir; BesideOS ISO dosyasını dağıtmaz.

Kimler için

Sunucu rollerini ve yönetim araçlarını öğrenmek isteyenler.

Nasıl görünür

Windows 11'e benzeyen görev çubuğu ve başlat menüsü; sunucu yönetim araçlarıyla gelir.

USB bellek olmadan kurulum

  1. ISO'nu seç veya indir: Kendi Windows Server 2025 ISO dosyanı seçersin ya da Microsoft'un resmi indirme sayfasından indirirsin. BesideOS ISO dosyası sağlamaz.
  2. İndirileni doğrula: ISO dosyasının bozuk olmadığını bu sayfadaki bölümden kontrol edersin.
  3. Elle kur: BesideOS şimdilik Windows kurulumunu kendisi yapmaz. Yedek aldıktan sonra kurulumu Microsoft yönergeleriyle yaparsın.

Gereksinimler

  • UEFI desteği olan 64 bit bilgisayar
  • Kurulum için yeterli boş disk alanı
  • Deneme veya geçerli bir sunucu lisansı
